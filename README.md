# Customer Churn Prediction — Churn AI

An end-to-end machine learning project that predicts customer churn using classification models and an interactive three-dimensional visualization.

## Project Overview

Customer churn occurs when customers stop using a company's products or services. This project uses machine learning to identify customers who may be at risk of leaving and help businesses make data-driven customer retention decisions.

## Machine Learning Models

The project explores and compares several classification algorithms:

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Gradient Boosting
- K-Nearest Neighbors (KNN)

A tuned Random Forest model is also evaluated.

## Evaluation Metrics

Models are evaluated using the following metrics:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Interactive Visualization

**Churn City** is a custom three-dimensional visualization that represents customer churn patterns across contract types and customer tenure groups.

## Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- Plotly
- Matplotlib and Seaborn
- Google Colab
